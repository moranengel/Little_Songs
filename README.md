# זמן לשיר! 🌈

נגן שירי ילדים לאייפון. אתר סטטי מוכן ל־GitHub Pages, ללא חשבון משתמש, שרת נתונים או Scripting.

## מה יש בחבילה

- ספרייה ריקה מוכנה להוספת שירים מהאייפון. השירים שמוסיפים באפליקציה נשמרים במכשיר בלבד ואינם נשלחים ל־GitHub.
- עיצוב קומפקטי לילדים, ניגון והשהיה, השיר הבא והקודם, זמן ופס התקדמות.
- הוספת קבצי שמע מהמכשיר ושמירתם מקומית ב־IndexedDB.
- שינוי שמות ואייקונים ומחיקת שירים מהמכשיר.
- שמירת שירי האתר להאזנה ללא אינטרנט, וכפתור בדיקה לשירים חדשים באתר.
- התקנה למסך הבית באמצעות Safari ו־manifest/service worker.

## העלאה ל־GitHub Pages — הגדרה חד־פעמית

הכי נוח לבצע את ההעלאה הראשונית ממחשב.

1. חלצו את קובץ ה־ZIP.
2. פתחו או צרו מאגר ב־GitHub. אם בוחרים מאגר ציבורי, כל קבצי הקוד והשירים שבו גלויים לאחרים.
3. העלו את **תוכן תיקיית האתר**, כך ש־`index.html`, `app.js`, `sw.js`, `songs.json` ותיקיות `songs` ו־`icons` יהיו בשורש המאגר, ולא בתיקייה פנימית.
4. במאגר פתחו `Settings` → `Pages`.
5. ב־`Build and deployment` בחרו `Deploy from a branch`, את ענף `main` ואת `/(root)`, ואז `Save`.
6. לאחר סיום הפרסום תופיע ב־Pages כתובת האתר. פתחו אותה בספארי באייפון.

אין צורך ב־npm, בבנייה, ב־GitHub Actions או במפתח API.

## מסך הבית והאזנה במצב טיסה

1. בספארי: שיתוף → הוספה למסך הבית. אם קיימת אפשרות ״פתיחה כיישום אינטרנט״, הפעילו אותה.
2. פתחו את האתר **מתוך האייקון החדש במסך הבית**.
3. פתחו ״להורים״ ולחצו ״שמירת כל השירים לאופליין״.
4. חכו להודעה שהשמירה הסתיימה ולכך שכל השירים מסומנים ״שמור באייפון״.
5. הפעילו מצב טיסה, סגרו את חלון הנגן ופתחו אותו מחדש מהאייקון. בחרו שיר לבדיקה.

הוספה למסך הבית לבדה אינה מורידה את השירים. אין צורך להוריד שוב אחרי כל פתיחה.
כדאי לבצע הורדות וייבוא מתוך האפליקציה במסך הבית: האחסון של פתיחה בספארי עשוי להיות נפרד.

## ניהול שירים באייפון

- ״להורים״ → ״הוספת שירים מהאייפון״: בוחרים קבצים מתוך ״קבצים״. הם מועתקים לאחסון המקומי של האתר, ואין בקשת העלאה לשרת.
- ״עריכת שירים״ → לחיצה על שיר או על העיפרון: משנים שם או אימוג׳י ושומרים.
- ״מחיקה״ מסירה את העותק המקומי. שיר שהגיע מהאתר גם מוסתר מהרשימה; הוא לא נמחק מ־GitHub. אפשר להחזיר שירים שהוסתרו דרך האזור להורים.
- השינויים של כל משתמש נשמרים רק במכשיר שלו. הם לא משנים את הספרייה אצל חברים ולא את הקוד ב־GitHub.

## הוספת שירים לכל המשתמשים באמצעות GitHub

1. הוסיפו קובץ לתיקיית `songs`.
2. הוסיפו רשומה ל־`songs.json`. לדוגמה:

```json
{
  "id": "new-song-07",
  "title": "שם השיר החדש",
  "icon": "🚂",
  "file": "songs/new-song.mp3"
}
```

הרשומה מצטרפת למערך `songs` הקיים. לכל שיר צריך להיות `id` ייחודי וקבוע.
לא חייבים לציין משך שיר; הנגן יקרא אותו בעת טעינה.
אפשר לערוך כאן גם את שמות ברירת המחדל של שירי האתר.

לחלופין, מתוך תיקיית האתר במחשב אפשר להריץ `python3 tools/build-catalog.py` כדי לזהות קבצים חדשים ולשמור שמות/אייקונים קיימים.
אחרי הפרסום משתמשים לוחצים ״בדיקת שירים חדשים באתר״ ואז שומרים שירים נוספים לאופליין.
שינוי שם אישי באייפון נשמר גם לאחר רענון רשימת האתר.

## עדכון הממשק

אם משנים HTML, CSS, JavaScript או אייקונים, יש לשנות גם את הסיומת `v4` של `CACHE` ב־`sw.js` לגרסה חדשה כמו `v5`. כך האפליקציה תשמור מעטפת חדשה בעת התחברות. השירים והעריכות המקומיות נשמרים בנפרד ואינם נמחקים בעדכון.
החלפת קובץ של שיר שכבר הורד לא מחליפה אוטומטית את העותק המקומי; לשיר חדש או הקלטה חדשה השתמשו ב־id ובשם קובץ חדשים.

## גבולות השמירה המקומית

- נדרש אינטרנט לפתיחה ולהורדה הראשונות, ולבדיקת עדכונים.
- הקוד והשירים המצורפים ל־GitHub נשמרים גם שם; שירים המיובאים דרך כפתור האתר נשארים מקומיים.
- אתר אינו מקבל גישה חופשית לתיקיות באייפון. הייבוא מתבצע לאחר בחירה מפורשת; לא מתבצעת סריקה אוטומטית של אפליקציית קבצים.
- ניקוי נתוני האתר או פינוי אחסון עלולים למחוק נתונים מקומיים. יש לשמור קובצי מקור ב״קבצים״. האפליקציה מבקשת שמירה מתמשכת כשהדפדפן תומך בכך, אך אין הבטחת גיבוי.
- פתיחה ישירה של `index.html` מתוך קובץ ZIP/אפליקציית קבצים אינה התקנת אפליקציה. יש להשתמש בכתובת HTTPS של האתר.
- פורמטים הניתנים להשמעה תלויים בתמיכת האייפון; MP3 ו־M4A רגילים הם אפשרויות מתאימות.
- שירי האתר הציבוריים אינם מוגנים באמצעות סיסמה. אין להעלות חומרים שצריכים להישאר פרטיים.

## קבצים

`index.html` — הממשק; `style.css` — העיצוב; `app.js` — הנגן והשמירה המקומית; `sw.js` — מעטפת אופליין; `songs.json` — רשימת שירי האתר; `manifest.webmanifest` ו־`icons` — התקנה למסך הבית; `songs` — קבצי השמע.
