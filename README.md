# זמן לשיר!

נגן שירי ילדים בעברית עם אחסון מקומי והאזנה ללא אינטרנט.

כתובת האתר: https://moranengel.github.io/Little_Songs/

גרסה: 2026.11.15.1. מקוד סביבת הבדיקות שאושר לאחר בדיקה במכשיר: 213b8cda827496bda2721f715a33aa3c6296398a.

- פלייליסטים אישיים עם חיפוש, סידור, נעיצה ושיוך שיר לכמה רשימות.
- הוספה ועריכת שירים מהמסך הראשי; בחירה מרובה במצב עריכה.
- נגן קבוע למעלה, ערבוב וחזרה, ושמירה במכשיר.
- מחיקה לפריטים שנמחקו, ביטול למשך חמש שניות ושחזור בהגדרות.
- גיבוי נייד בשם Backup.little-songs, כולל שמע, שמות, אייקונים ופלייליסטים. השמירה דורשת פעולה של המשתמש.
- אחסון שמע כבתים עצמאיים עם בדיקת גודל וחתימה; קבצים ישנים אינם מומרים אוטומטית.
- בדיקת תקלה בניגון ותיקון שמע מגיבוי תקין תוך שימור הפרטים הנוכחיים.

## אחסון ופרסום

זהות הסביבה הראשית נשמרת: IndexedDB בשם little-songs-web-v1, גרסת מסד 1; מטמון little-songs-shell: לפי נתיב האתר. סביבת הבדיקות משתמשת במסד ומטמון נפרדים. נתוני השירים המקומיים אינם נשמרים ב־GitHub.

העדכון אינו מוחק או מאפס נתוני משתמש. אפשר לייבא גיבוי מסביבת הבדיקות, אך זה אינו קורה אוטומטית. שחזור מלא מחיל גם את הפרטים מהגיבוי; תיקון שמע בלבד שומר את הפרטים הנוכחיים. שמרי עותק תקין מחוץ לדפדפן, משום שניקוי נתוני אתר מוחק אחסון מקומי.

אחרי שינוי JS או CSS הריצו python3 tools/version-assets.py. שמרו את הקבצים עם הגיבוב ואת ההפניות ב־index.html וב־sw.js יחד.

בדיקות: node tests/production.test.cjs ולאחריו כל קובצי tests/*.test.cjs. לפני פרסום יש לאשר את הגרסה בסביבת הבדיקות.

גרסה זו מוסיפה גובה מפורש לחלון ההגדרות ואייקון משיכת גרסה בפס העליון. לחיצה ממתינה להכנת קובצי העדכון לפני רענון; כשל חיבור משאיר את הדף הנוכחי פתוח.
